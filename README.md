### 推箱子
1.将 Program.cs 和 Sokoban.csproj 复制到一个文件夹中（例如复制到“新建文件夹”中）

2.右键“新建文件夹”，选择用 VScode 打开

3.在终端输入 dotnet build 命令来生成 Sokoban.exe 文件

4.在资源管理器中打开 bin\Debug\net8.0 ,在这个文件夹中新建一个名为 Map 的文件夹

5.将 1.XLG 文件复制到刚刚创建的 Map 文件夹中

6.运行 Sokoban.exe 看看效果

### 地图创建器
1.运行 Sokoban.exe

2.输入 2 回车

3.输入地图的最大高度（行数）并回车

4.输入地图的最大宽度（列数）并回车

5.对照自己找的地图图片输入对应的数字

6.使用 Back键（退格键/删除键） 删除上一次的输入

7.完成整地图后程序会自动将新地图添加到 Map 文件夹里，此时可以直接开始游戏了！
